01El problema

Cada plataforma tiene su métrica nativa (Reddit karma, LinkedIn SSI, HN karma, h-index). No existe una métrica unificada cross-platform que mida autoridad real para un profesional. Tampoco existe un sistema sistemático para decidir qué plataformas pesan para un actor vs un abogado vs un CEO B2B. Resultado: 90% de los servicios "personal branding" en mercado son coachs LinkedIn-only que ignoran 6 de las 7 capas que un LLM, un buscador y un decisor humano consultan al evaluar credibilidad.

02La solución

Digital Karma Index
Score 0-1000 compuesto sobre 5 capas (Earned · Discoverability · LLM Visibility · Trust · Owned), con tiers cualitativos de Invisible a Top of field globally.
Authority Database
86 plataformas catalogadas con scoring propietario en 3 dimensiones (Google · LLM · Trust 0-100), priorizadas por sector y objetivo cliente vía script Python.
Plan 90 días
3 fases (Foundation · Build · Scale) con entregables por sub-fase, 5-8 plataformas core elegidas en kickoff, dashboard quincenal.

02La fórmula DKI

# Digital Karma Index · score 0-1000 cross-platform DKI = (E × 0.40) + (D × 0.20) + (L × 0.15) + (T × 0.15) + (O × 0.10) E = Earned Authority # followers + karma nativos, ponderados por sector relevance D = Discoverability # Wikipedia + Wikidata + Schema.org + Google KP + sector dirs L = LLM Visibility # vía GEORadar: SoV + Position + Sentiment + Co-branding T = Trust Signals # Recommendations + Reviews + Press + Verified + TEDx O = Owned Anchor # sitio personal DA + newsletter + long-form + libros

Pesos racionales

  • E 40% · audiencia construida = output más visible, primer signal que ve un decisor
  • D 20% · sin discoverability nadie te encuentra (multiplica el valor de las otras capas)
  • L 15% · diferencial Zoopa (capa que ningún SaaS de personal branding mide). Subirá a 20% en V2 cuando GEORadar API integre auto
  • T 15% · señales que un tercero verifica (recommendations, reviews, press cualificada)
  • O 10% · base estructural pero menos visible que earned. Foundation no negociable

Tiers cualitativos

0–300 · entry tiers
Invisible (0-100) · Emerging (100-300). Gap principal: sin sitio personal + sin presencia consistente.
300–700 · niche tiers
Established en niche (300-500) · Recognized regional/sectorial (500-700). Suele ser donde están la mayoría de profesionales senior antes de AB90.
700–1000 · leadership tiers
Leading authority (700-900) · Top of field globally (900-1000). Pocos llegan; requiere combinación de TEDx + Wikipedia + press tier-1.

§ 03 · platform authority database 03

86 plataformas scored
+ mantenimiento trimestral.

El skill no usa una lista plana de plataformas. Usa una base de datos viva con scores propietarios en 3 dimensiones, mantenida trimestralmente con cadencia disciplinada. Es lo que distingue karma-booster de un simple "catálogo".

01Las 3 dimensiones de scoring (0-100)

DimensiónQué mideEvidencia usada
authority.google Cuánto rankea esta plataforma en SERP para queries de identidad (name + sector). Combina DA + Knowledge Panel support + Schema.org nativa. Sample manual de SERPs · inspección de Knowledge Panels reales · datos Ahrefs públicos · análisis site: queries
authority.llm Frecuencia con la que ChatGPT/Claude/Gemini/Perplexity/AIO citan esta fuente al describir profesionales o marcas. Common Crawl presence · observación directa GEORadar (16+ marcas, ~9M menciones) · sample queries manuales por LLM · reportes públicos Perplexity
authority.trust Peso como señal de credibilidad para un decisor humano (recruiter · prospect · journalist · board). Friction de signup · verifiability por terceros · industry recognition · halo de la plataforma anfitriona

03Compute per cliente (script authority_score.py)

# Pesos según objetivo del cliente objective google: w_google=0.55 w_llm=0.20 w_trust=0.25 objective llm (GEO): w_google=0.20 w_llm=0.55 w_trust=0.25 objective trust B2B: w_google=0.25 w_llm=0.20 w_trust=0.55 objective balanced: w_google=0.40 w_llm=0.30 w_trust=0.30 # Modifiers aplicados sector_bonus × 1.30 # si match con platform.sectors_bonus bandwidth_penalty − (effort × {0.4 low / 0.2 med / 0.05 high}) status_multiplier × {1.05 emerging / 1.00 live / 0.85 declining / 0.00 dead}

Ejemplos validados: tech + LLM obj → HN (99.9★) · Reddit (99.3★) · Wikipedia (92.8) · X (89.1★) ·   designer + Google obj → Wikipedia (86.8) · Scholar (83.2) · IMDb (81.0) · Behance (79.2★) ·   lawyer + Trust obj → JD Supra (96.6★) · Justia (96.4★) · Wikipedia (91.2)

04Sistema de mantenimiento (cadencia trimestral)

Cuatro reviews al año · 90 min cada una
Q1 · 25 ene · Q2 · 25 abr · Q3 · 25 jul · Q4 · 25 oct

Owner: Carlos Ortet + Mer Canet. Output: PR al repo con cambios + commit firmado.
Checklist 4 bloques por review
1 · Health check de las 86 plataformas (DNS · status · scores ±10pt)
2 · Scan candidatas (Product Hunt · HN · TechCrunch · GEORadar runs)
3 · Demotion de plataformas en decline → dead
4 · Re-scoring evidence pass para 5-10 plataformas rotativas

Triggers ad-hoc (fuera de trimestre): plataforma muere o pivota · major algorithm change Google · GEORadar reporta cambio detectable · cliente nuevo en sector no cubierto · nueva plataforma con crecimiento >100% YoY.

05Honestidad sobre V1

Scores actuales son educated estimates basados en conocimiento operacional Zoopa (16+ marcas en GEORadar, ~9M menciones analizadas), NO en medición sistemática automatizada. Son direccionales (±5pt dentro de tier = ruido; diferencias de tier = reales). Roadmap empírico: V1.5 GEORadar API integration → authority.llm auto-update trimestral. V1.7 Common Crawl + Ahrefs check → authority.google empírico.

05Riesgos y tradeoffs

  • Scores V1 son estimates direccionales, no empíricos. Mitigación: cadencia trimestral + roadmap V1.5 hacia empírico. Defensa ante cliente documentada en methodology.md
  • Plataformas mueren o pivotan rápido (HARO→Connectively, Twitter→X). Mitigación: triggers ad-hoc fuera de trimestre + status tracking riguroso
  • 20 sectores no cubren todo; nichos quedan en catch-all dinámico. Mitigación: V1.3+ amplía a 25-30 sectores con clientes externos
  • Sin auto-medición de LLM citation en V1. Mitigación inmediata: muestreo manual + GEORadar runs · resolución total: V1.5
El compromiso del skill. Lista de 86 plataformas + sistema vivo que las prioriza con scores defendibles + mantenimiento disciplinado para no envejecer. No prometemos cubrir 86 canales en 90 días con cada cliente: prometemos elegir bien las 5-8 core y ejecutar a fondo.
